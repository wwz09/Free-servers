## Shadowrockets

[Shadowrockets](https://shadowrockets.app) は **Android、Windows、macOS、Linux** 向けのクライアントを提供しています。無料ノードを内蔵し、ワンタップ接続と遅延テストに対応するほか、任意で加入できる会員プランも用意しています。機能と会員特典はプラットフォームやバージョンによって異なります。

| プラットフォーム | インストールパッケージの選択 |
| --- | --- |
| Android | デバイスのアーキテクチャに合った APK を選択するか、Google Play からインストールしてください。 |
| Windows | x64、ARM64。 |
| macOS | Intel は x64、Apple Silicon は ARM64 を使用してください。 |
| Linux | x64、ARM64。deb とポータブルパッケージを提供しています。 |

**ダウンロード：** [公式サイトからダウンロード](https://shadowrockets.app/download/) · [Google Play](https://play.google.com/store/apps/details?id=com.v2cross.proxy)

Android プロジェクトとリリース：[GitHub](https://github.com/Pawdroid/shadowrocket_for_android) · [Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases)。インストール方法とリリース情報は[変更履歴](https://shadowrockets.app/changelog/)をご覧ください。

## その他の製品とダウンロード先

### ShadowShare

ノードとサブスクリプションを共有するツールです。Android と iOS のダウンロード先を用意しています。

[公式サイト](https://shadowsharing.com) · [iOS App Store](https://apps.apple.com/cn/app/shadowshare/id1612647259)

### Pawdoll

VPN クライアントです。製品情報とダウンロードは[公式サイト](https://pawdollvpn.com)をご覧ください。

### Surflare

Surflare は VPN とプロキシサービスを提供しています：

- Windows、macOS、Linux、Android、iOS 向けのクライアントを提供しています。
- VPN アプリはスマートルーティングとマルチホップ VPN に対応しています。
- プロキシサービスは SOCKS5 と HTTP に対応し、それぞれのプロキシ設定に対応したソフトウェアで利用できます。

**クーポンコード：`pawdroid`。** 実際の割引内容と対象プランは決済ページでご確認ください。

[公式サイト](https://www.surflare.com/)

### サブスクリプションの形式と互換性

| 設定の種類 | 使い方 |
| --- | --- |
| **ノードリンク / 一般的な V2Ray サブスクリプション** | 通常はノードリンクの一覧で、全体が Base64 でエンコードされている場合もある。クライアントが該当プロトコルに対応している必要がある。 |
| **Clash / Mihomo YAML** | ノード、プロキシグループ、ルールを含められる。拡張フィールドへの対応はコアによって異なる場合がある。 |
| **sing-box JSON** | クライアントが使用する sing-box コアのバージョンとの互換性が必要。 |
| **Surge / Quantumult X / Loon などの専用設定** | それぞれ独自の設定仕様がある。一部の構文が似ていても、完全な互換性は保証されない。 |

異なる形式をそのまま相互に置き換えることはできません。変換によってルール、DNS、プロキシグループ、プロトコルのパラメーターが失われることがあります。インポート前に、使用するクライアントとコアのバージョンを確認してください。Stash などのクライアントも、すべての Mihomo 拡張への対応を保証するものではありません。

変換が必要な場合は、[サブスクリプション変換ツール](https://acl4ssr-sub.github.io)を利用できます。個人の認証情報を含むサブスクリプションは、信頼できるサービスでのみ処理してください。

### 利用手順

1. システムと CPU アーキテクチャに合うクライアントを公式の配布元からダウンロードします。
2. クライアント内蔵のノードを使用するか、対応するサブスクリプションや設定をインポートしてノード一覧を更新します。
3. ノードを選んで遅延を測定し、接続後に実際のアクセス状況を確認します。

### サブスクリプションの更新と接続トラブルの対処

- **サブスクリプションの更新：** クライアント内でサブスクリプションを更新し、最新のノード一覧を取得します。更新に成功しても、その時点でノードが利用できるとは限りません。
- **インポートできない場合：** サブスクリプションの URL が欠けていないか確認します。取得に失敗する場合はネットワークとエラーメッセージを確認し、解析に失敗する場合は形式とクライアントのコアバージョンを確認してください。
- **接続できない場合：** まずサブスクリプションを更新して別のノードを試し、その後、クライアントのエラーメッセージに従ってプロキシまたは VPN モードを確認してください。

遅延の結果が示すのは今回のテストの状況だけです。ノードの安全性を示すものではなく、すべてのサービスへのアクセスを保証するものでもありません。
