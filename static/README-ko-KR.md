## Shadowrockets

[Shadowrockets](https://shadowrockets.app)는 **Android, Windows, macOS, Linux** 클라이언트를 제공합니다. 무료 노드가 내장되어 있으며 원터치 연결, 지연 시간 테스트 및 선택형 멤버십을 지원합니다. 세부 기능과 멤버십 혜택은 플랫폼과 버전에 따라 다릅니다.

| 플랫폼 | 설치 패키지 선택 |
| --- | --- |
| Android | 기기 아키텍처에 맞는 APK를 선택하거나 Google Play에서 설치하세요. |
| Windows | x64, ARM64. |
| macOS | Intel은 x64, Apple Silicon은 ARM64를 사용하세요. |
| Linux | x64, ARM64. deb 및 포터블 패키지를 제공합니다. |

**다운로드:** [공식 웹사이트에서 다운로드](https://shadowrockets.app/download/) · [Google Play](https://play.google.com/store/apps/details?id=com.v2cross.proxy)

Android 프로젝트 및 릴리스: [GitHub](https://github.com/Pawdroid/shadowrocket_for_android) · [Releases](https://github.com/Pawdroid/shadowrocket_for_android/releases). 설치 및 버전 안내는 [변경 기록](https://shadowrockets.app/changelog/)을 확인하세요.

## 기타 제품 및 다운로드 링크

### ShadowShare

노드 및 구독 공유 도구로, Android와 iOS 다운로드 링크를 제공합니다.

[공식 웹사이트](https://shadowsharing.com) · [iOS App Store](https://apps.apple.com/cn/app/shadowshare/id1612647259)

### Pawdoll

VPN 클라이언트입니다. 제품 안내 및 다운로드는 [공식 웹사이트](https://pawdollvpn.com)를 확인하세요.

### Surflare

Surflare는 VPN 및 프록시 서비스를 제공합니다:

- Windows, macOS, Linux, Android, iOS 클라이언트를 제공합니다.
- VPN 앱은 스마트 라우팅과 멀티홉 VPN을 지원합니다.
- 프록시 서비스는 SOCKS5와 HTTP를 지원하며, 해당 프록시 설정을 지원하는 소프트웨어에서 사용할 수 있습니다.

**할인 코드: `pawdroid`.** 실제 할인 혜택 및 적용 요금제는 결제 페이지를 기준으로 합니다.

[공식 웹사이트](https://www.surflare.com/)

### 구독 형식과 호환성

| 설정 유형 | 사용 안내 |
| --- | --- |
| **노드 링크 / 일반적인 V2Ray 구독** | 일반적으로 노드 링크 목록이며, 전체가 Base64로 인코딩되어 있을 수도 있음. 클라이언트가 해당 프로토콜을 지원해야 함. |
| **Clash / Mihomo YAML** | 노드, 프록시 그룹 및 규칙을 포함할 수 있음. 확장 필드 지원은 코어마다 다를 수 있음. |
| **sing-box JSON** | 클라이언트가 사용하는 sing-box 코어 버전과 호환되어야 함. |
| **Surge / Quantumult X / Loon 등의 전용 설정** | 각각 고유한 설정 규격이 있음. 일부 구문이 비슷하더라도 완전한 호환성이 보장되지는 않음. |

서로 다른 형식을 그대로 바꿔 사용할 수는 없습니다. 변환 과정에서 규칙, DNS, 프록시 그룹 또는 프로토콜 매개변수가 누락될 수 있으므로 가져오기 전에 대상 클라이언트와 코어 버전을 확인하세요. Stash 등의 클라이언트도 모든 Mihomo 확장을 지원한다고 보장할 수는 없습니다.

변환이 필요하면 [구독 변환 도구](https://acl4ssr-sub.github.io)를 사용할 수 있습니다. 개인 인증 정보가 포함된 구독은 신뢰할 수 있는 서비스에만 맡기세요.

### 사용 절차

1. 시스템과 CPU 아키텍처에 맞는 클라이언트를 공식 경로에서 다운로드하세요.
2. 클라이언트가 제공하는 내장 노드를 사용하거나, 지원되는 구독 또는 설정을 가져온 뒤 노드 목록을 업데이트하세요.
3. 노드를 선택해 지연 시간을 테스트하고, 연결 후 실제 접속 상태를 확인하세요.

### 구독 업데이트 및 연결 문제 해결

- **구독 업데이트:** 클라이언트에서 구독을 업데이트하여 최신 노드 목록을 가져오세요. 업데이트에 성공했다고 해서 현재 노드를 사용할 수 있다는 뜻은 아닙니다.
- **가져올 수 없는 경우:** 구독 주소가 빠짐없이 입력되었는지 확인하세요. 가져오기 요청에 실패하면 네트워크와 오류 메시지를 확인하고, 파싱에 실패하면 구독 형식과 클라이언트 코어 버전을 확인하세요.
- **연결되지 않는 경우:** 먼저 구독을 업데이트하고 다른 노드를 시도한 뒤, 클라이언트의 오류 메시지에 따라 프록시 또는 VPN 모드를 확인하세요.

지연 시간 결과는 해당 테스트의 상태만 반영합니다. 노드의 안전성을 뜻하지 않으며 모든 서비스에 접속할 수 있다는 보장도 아닙니다.
